Year-End Database Refresh

⚠️ Destructive Operation — This Cannot Be Undone

Performing a database refresh will permanently delete the following data for the current school year:

  • All current book reservations
  • All volunteer logon history
  • All non-admin volunteer accounts
  • All classes and their student rosters
  • All lost and damaged book copies (and any books with no remaining copies)

A backup of all affected collections will be saved to the database before the refresh runs. The backup is a best-effort server-side copy and is not a guaranteed point-in-time snapshot.
